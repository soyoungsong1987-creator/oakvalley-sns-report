90홀 페어라이어 리뷰 이벤트는 조회 4,677회로 가장 높았습니다. 프로모션도 단순 가격 공지보다 참여 조건·고객 행동이 명확한 기획이 필요합니다.

03 · CHANNEL IDENTITY
4개 CC의 구분감 강화

통합 계정에서 코스 소개와 특가·회원 안내가 혼재합니다. 각 CC의 차별화된 경험을 유지하면서 90홀 통합 브랜드로 연결하는 콘텐츠 구조를 제안합니다.

상기 해석은 20개 게시물의 기술적 비교와 콘텐츠 관찰에 근거한 가설입니다. 광고 집행 여부, 팔로워 규모, 게시 후 경과 기간 등을 통제한 인과 분석은 아닙니다.

범위 직접 발행 게시물만 포함합니다. 외부 계정 발행 공동 게시물(collaborative)은 현재 연결 방식에서 API 오류가 발생해 제외했습니다. 따라서 전체 계정 게시물 수 또는 전체 성과로 해석해서는 안 됩니다. 자체 발행 게시물의 공동 작성자 유무 역시 별도 검증이 필요합니다.

지표 도달은 게시물별 고유 계정 도달, 조회는 게시물별 누적 조회입니다. 여러 게시물 도달을 합산한 값은 계정 전체 고유 도달이 아닙니다. 참여율은 (좋아요+댓글+저장+공유) ÷ 게시물 도달 × 100이며, 보고서에서는 게시물별 참여율의 단순 평균을 사용합니다.

한계 팔로워 증감, 스토리, 광고 집행, 프로필 방문, 예약 전환, 원본 이미지의 시각적 검토는 이번 조회에 포함되지 않았습니다. 프로퍼티·콘텐츠 분류는 게시물 캡션에 기반한 분석용 수작업 분류입니다.

배포 본 HTML은 조회 데이터를 포함하는 정적 보고서이며 Windsor.ai 연동 해제 후에도 표시됩니다. 외부 공개 저장소에 게시할 경우 내부 성과 데이터가 공개될 수 있으므로 접근 권한을 검토해 주세요.
